# SALESBOT Training System - На Счастье Academy

Внутренняя система обучения и академия для компании "На Счастье".

## Обзор

Это комплексная обучающая платформа, которая объединяет:
- **FastAPI Backend**: RESTful API для управления обучающими модулями, уроками и прогрессом пользователей
- **Telegram Bot**: Интерактивный интерфейс обучения для сотрудников
- **Модульная архитектура**: Легко расширяется новыми обучающими модулями (поддержка YAML и Python модулей)
- **Система ролей**: Персонализированное обучение для разных должностей
- **TTS (Text-to-Speech)**: Озвучка уроков с поддержкой женского и мужского голоса

## Новые возможности (v2.0)

### Автоматическая загрузка модулей
Система теперь автоматически загружает модули из:
- YAML файлов из `data/academy/modules/`
- Python модулей из `modules/academy/` (файлы `module*.py` и `module_*.py`)

Просто создайте новый файл модуля, и он автоматически появится в системе!

## Установка

1. **Установка зависимостей**:
```bash
cd botfinal
pip install -r requirements.txt
```

2. **Настройка окружения** (создайте файл `.env` в корневой папке):
```bash
# Telegram Bot
TELEGRAM_BOT_TOKEN=ваш-токен-бота

# Backend
BACKEND_URL=http://127.0.0.1:8080
BACKEND_BASE_URL=http://127.0.0.1:8080

# TTS Service (опционально - для AssemblyAI)
VOICE_API_KEY=ваш-api-ключ
VOICE_API_BASE_URL=https://api.assemblyai.com/v2

# Admin Access (опционально)
ADMIN_API_KEY=ваш-секретный-ключ
```

Для получения токена Telegram бота:
- Напишите [@BotFather](https://t.me/botfather) в Telegram
- Используйте команду `/newbot`
- Следуйте инструкциям для создания бота

## API Эндпоинты

### Модуль Academy (`/academy/v1`)

#### Модули и уроки
- `GET /academy/v1/modules` - Список всех модулей
  - Query: `role` (sales_manager, generator, admin), `user_id`
- `GET /academy/v1/modules/{module_id}` - Детали модуля
- `GET /academy/v1/modules/{module_id}/lessons` - Список уроков
- `GET /academy/v1/modules/{module_id}/lessons/{lesson_id}` - Получить урок

#### TTS Озвучка (НОВОЕ!)
- `POST /academy/v1/lessons/{module_id}/{lesson_id}/tts` - Генерация аудио
  - Body: `{"voice_type": "ru_female"}` или `"ru_male"`
  - Возвращает: `{"audio_url": "http://..."}`

#### Прогресс
- `POST /academy/v1/progress/{user_id}/lessons/{module_id}/{lesson_id}/complete` - Завершить урок
- `POST /academy/v1/progress/{user_id}/lessons/{module_id}/{lesson_id}/start` - Начать урок
- `GET /academy/v1/progress/{user_id}` - Прогресс пользователя

#### Тесты
- `POST /academy/v1/modules/{module_id}/tests/{test_id}/submit` - Отправить тест
  - Body: `{"user_id": "...", "answers": [0, 2, 1, ...]}`

#### Поиск
- `GET /academy/v1/search?query=...` - Поиск контента (русский язык)

#### Управление ролями
- `POST /academy/v1/users/{user_id}/role` - Установить роль
  - Body: `{"role": "sales_manager"}`
- `GET /academy/v1/users/{user_id}/role` - Получить роль

#### Админ-аналитика (требуется X-Admin-Token)
- `GET /academy/v1/admin/users` - Список пользователей
- `GET /academy/v1/admin/users/{user_id}/progress` - Детальный прогресс
- `GET /academy/v1/admin/stats/summary` - Сводная статистика

### Основные эндпоинты

- `GET /` - Информация о сервисе
- `GET /api/public/v1/health` - Проверка здоровья
- `POST /voice/v1/tts` - Генерация text-to-speech
  - Params: `text`, `voice_type` (ru_female, ru_male)
- `GET /voice/v1/audio/{filename}` - Получить аудиофайл
- `GET /data/tts/{filename}` - Статические TTS файлы

## Роли пользователей

| Роль | Описание | Доступ |
|------|----------|--------|
| **admin** | Администратор | Все модули + панель управления |
| **user** | Пользователь | Все обучающие модули |

Доступ определяется паролем из `.env` файла (ADMIN_PASSWORD или USER_PASSWORD).

## Команды Telegram Bot

- `/start` - Приветствие
- `/login` - Вход в систему по паролю
- `/help` - Показать справку
- `/academy` - Просмотр модулей (фильтрация по роли)
- `/progress` - Посмотреть прогресс
- `/search <запрос>` - Поиск контента

### Типичный пользовательский поток

1. `/start` → выбор роли
2. `/academy` → просмотр доступных модулей
3. Выбор модуля → просмотр уроков
4. Выбор урока → чтение/прослушивание
5. 🔊 Кнопка "Послушать урок" → выбор голоса (женский/мужской)
6. Получение голосового сообщения
7. ✅ Отметить как пройденный
8. Прохождение тестов
9. `/progress` → проверка прогресса

## Создание нового модуля

### Вариант 1: Python модуль (рекомендуется для новых модулей)

Создайте файл `modules/academy/module_название.py`:

```python
"""
Module Description
"""

module_id = "module_название"
title = "Название модуля"
description = "Описание модуля"
role_visibility = ["sales_manager", "generator"]  # или ["admin"]
estimated_duration_minutes = 60

lessons = [
    {
        "id": "m_l1",
        "title": "Урок 1",
        "type": "text",
        "content_ru": """Содержание урока на русском языке...""",
        "duration_minutes": 20,
        "order": 1
    }
]

tests = [
    {
        "id": "m_test1",
        "title": "Тест",
        "passing_score": 70,
        "questions": [
            {
                "id": "q1",
                "type": "single",
                "question": "Вопрос?",
                "options": ["Вариант 1", "Вариант 2"],
                "correct_index": 0
            }
        ]
    }
]
```

### Вариант 2: YAML файл

Создайте файл `data/academy/modules/module_название.yaml`:

```yaml
id: "module_название"
title: "Название модуля"
description: "Описание"
roles: ["sales_manager"]
level: 1
estimated_duration_minutes: 60

lessons:
  - id: "m_l1"
    title: "Урок 1"
    type: "text"
    content: "Содержание урока..."
    order: 1

tests:
  - id: "m_test1"
    title: "Тест"
    passing_score: 70
    questions:
      - id: "q1"
        type: "single"
        question: "Вопрос?"
        options:
          - "Вариант 1"
          - "Вариант 2"
        correct_index: 0
```

Модуль автоматически загрузится при следующем запуске!

### TTS Провайдеры

Система поддерживает два TTS провайдера:

1. **gTTS (Google Text-to-Speech)** - используется по умолчанию
   - Не требует API ключа
   - Бесплатный
   - Требует интернет-соединение
   - Поддержка русского языка

2. **AssemblyAI** - опциональный (установить VOICE_API_KEY)
   - Требует API ключ
   - Профессиональное качество
   - Note: AssemblyAI в основном для транскрипции, TTS может требовать партнёрские сервисы

### Автозагрузка модулей

Система сканирует:
- `data/academy/modules/*.yaml` - YAML модули
- `modules/academy/module*.py` - Python модули (F-модули)
- `modules/academy/module_*.py` - Python модули (P-модули)

Все найденные модули автоматически загружаются и регистрируются.

## Безопасность

- Админ-эндпоинты защищены через `X-Admin-Token` заголовок
- Установите `ADMIN_API_KEY` в `.env` для защиты
- Никогда не коммитьте `.env` файл в репозиторий
- Используйте `.gitignore` для исключения конфиденциальных файлов
