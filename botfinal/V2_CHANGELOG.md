### 7. Механика значков (Badges)
**Команда:** `/badges`  
**API:** `GET /academy/v1/users/{user_id}/badges`

**Изменённые файлы:**
- `progress_repository.py` - таблица academy_badges, методы
- `service.py` - автоматическое начисление
- `simple_telegram_bot.py` - команда /badges
- `router.py` - API endpoint

**База данных:**
```sql
CREATE TABLE academy_badges (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,
    badge_type TEXT NOT NULL,
    badge_name TEXT NOT NULL,
    badge_description TEXT,
    earned_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, badge_type)
)
```

**Типы значков:**
- 🎖 Первый модуль пройден
- 🧠 Один тест на 100%
- 🔥 3 дня подряд обучение

**Автоматическое начисление:**
- При завершении урока
- При прохождении теста
- При проверке дневного прогресса

### 8. Логи прогресса по дням
**Команда:** `/progress_daily`  
**API:** `GET /academy/v1/users/{user_id}/daily-progress?days=30`

**Изменённые файлы:**
- `progress_repository.py` - таблица, методы
- `service.py` - автоматическое обновление
- `simple_telegram_bot.py` - команда
- `router.py` - API endpoint

**База данных:**
```sql
CREATE TABLE academy_daily_progress (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,
    date DATE NOT NULL,
    lessons_completed INTEGER DEFAULT 0,
    minutes_studied INTEGER DEFAULT 0,
    tests_passed INTEGER DEFAULT 0,
    UNIQUE(user_id, date)
)
```

**Автоматическое обновление:**
- Завершение урока → +lessons_completed, +minutes_studied
- Прохождение теста → +tests_passed
- SQLite-совместимый UPDATE/INSERT

### 9. Push-уведомления о новых модулях
**Новый файл:** `notification_service.py`

**Функциональность:**
- Автоматическая отправка уведомлений всем пользователям
- Интеграция с `/reload?notify_users=true`
- Пакетная обработка (batching) по 100 пользователей
- Логирование в `data/notifications.log`

**Методы:**
- `notify_new_module(module_title, module_description, user_ids)`
- `_send_telegram_message(client, user_id, message)`
- `_log_notification(notification_type, subject, recipient_count)`

**Формат уведомления:**
```
📚 Новый обучающий модуль!

*Название модуля*

Описание модуля

Начните обучение прямо сейчас! Используйте команду /academy для доступа к модулю.
```

### 10. Улучшение TTS (Text-to-Speech)
**Изменённые файлы:**
- `tts_service.py` - кэширование, таймауты, ошибки
- `router.py` - cache_key в запросах

**Улучшения:**

1. **Кэширование:**
   - Проверка существования файла перед генерацией
   - Имя файла: `{module_id}_{lesson_id}_{voice_type}.mp3`
   - Возврат `"cached": true` в ответе

2. **Защита от таймаутов:**
   - `timeout=30` в gTTS
   - Автоматическое сокращение текста > 5000 символов
   - Повторная попытка при ошибке

3. **Обработка ошибок:**
   - Логирование всех ошибок
   - Понятные сообщения об ошибках
   - Graceful degradation

4. **Улучшенные имена файлов:**
   - До: `{uuid}.mp3`
   - После: `module4_client_service_m4_l1_ru_female.mp3`
