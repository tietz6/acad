# V2 Quick Start Guide - Корпоративная обучающая система

## 🚀 Быстрый старт

### Новые команды для пользователей:

```
/profile         - Личный кабинет (роль, статистика, рейтинг)
/badges          - Ваши заработанные значки
/progress_daily  - Дневной прогресс обучения
```

### Новые команды для администраторов:

```
/admin   - Панель администратора с интерактивным меню
/reload  - Перезагрузка модулей без перезапуска системы
```

## 📊 Что нового в V2?

### 1. Личный кабинет (/profile)
Показывает вашу полную статистику:
- 📊 Процент выполнения
- ⭐ Рейтинг 0-100
- 📚 Модули в процессе
- 🏆 Количество значков

### 2. Система значков
Автоматически зарабатывайте значки за достижения:
- 🎖 Первый модуль пройден
- 🧠 Тест на 100%
- 🔥 3 дня подряд обучение

### 3. Дневной прогресс
Отслеживайте свою активность по дням:
- Уроков завершено
- Минут изучено
- Тестов пройдено

### 4. Админ-дашборд
Полная статистика для руководителей:
- 👥 Статистика по сотрудникам
- 📚 Прогресс по модулям
- 📝 Результаты тестов
- 🔄 Управление модулями

### 5. Улучшенный поиск
Теперь поиск работает по:
- Названиям и описаниям
- Содержимому уроков
- Вопросам тестов
- **Ключевым словам** (новое!)

### 6. Push-уведомления
Автоматические уведомления о новых модулях для всех пользователей.

### 7. Улучшенная озвучка (TTS)
- ⚡ Кэширование - быстрая повторная загрузка
- 🛡 Защита от таймаутов
- 📁 Лучшие имена файлов

## 🔧 Настройка

### 1. Создайте .env файл:
```bash
cp .env.example .env
```

### 2. Заполните обязательные поля:
```env
TELEGRAM_BOT_TOKEN=your_token_here
ADMIN_API_KEY=your_secure_key_here
ADMIN_PASSWORD=your-secure-admin-password
USER_PASSWORD=your-secure-user-password
```

### 3. Запустите систему:
```bash
# Backend
python main.py

# Bot (в другом терминале)
python simple_telegram_bot.py
```

## 📚 Добавление нового модуля

### 1. Создайте файл модуля:
```python
# modules/academy/module_new.py

module_id = "module_new"
title = "Новый модуль"
description = "Описание модуля"
role_visibility = ["admin"]  # Только админы или оставить пустым для всех
keywords = ["новый", "обучение", "модуль"]  # Для поиска!

lessons = [
    {
        "id": "new_l1",
        "title": "Урок 1",
        "type": "text",
        "content": "Содержимое урока..."
    }
]

tests = []
```

### 2. Перезагрузите модули:
```bash
# Через бота (нужна роль admin)
/reload

# Или через API
curl -X POST -H "X-Admin-Token: your_key" \
  "http://localhost:8080/academy/v1/admin/reload?notify_users=true"
```

### 3. Готово! 
Все пользователи получат уведомление о новом модуле.

## 🔐 Безопасность

- ✅ Все админские команды проверяют роль
- ✅ API защищён токеном X-Admin-Token
- ✅ SQLite база данных с индексами
- ✅ Валидация входных данных

## 📈 Мониторинг

### Просмотр статистики:
```
/admin → Статистика по сотрудникам
```

Показывает:
- Общее количество пользователей
- Активные пользователи
- Средний процент прохождения
- Топ модули

### Прогресс по модулям:
```
/admin → Статистика по модулям
```

Для каждого модуля:
- Сколько начали
- Сколько завершили
- Средний прогресс
- Топ-3 пользователя

## 💡 Советы

1. **Используйте keywords** в модулях для лучшего поиска
2. **Проверяйте badges** регулярно - это мотивирует!
3. **Админам**: используйте /admin для мониторинга команды
4. **Добавили модуль?** Не забудьте `notify_users=true` при reload

## 📞 API Endpoints

### Для пользователей:
- `GET /academy/v1/users/{user_id}/profile` - профиль
- `GET /academy/v1/users/{user_id}/badges` - значки
- `GET /academy/v1/users/{user_id}/daily-progress` - дневной прогресс

### Для администраторов (требуется X-Admin-Token):
- `POST /academy/v1/admin/reload` - перезагрузка модулей
- `GET /academy/v1/admin/stats/summary` - общая статистика
- `GET /academy/v1/admin/modules/stats` - статистика по модулям
- `GET /academy/v1/admin/users` - список пользователей
