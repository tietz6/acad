## ✅ Реализованные функции V3

### 1️⃣ Система уровней и рангов (Levels & Ranks)

**База данных:** Таблица `academy_levels`

**Поля:**
- `user_id` - ID пользователя
- `level` - Текущий уровень (1-10)
- `xp` - Накопленный опыт
- `xp_to_next` - Опыт до следующего уровня
- `updated_at` - Время последнего обновления

**Ранги:**
| Уровень | Ранг | Требуется XP |
|---------|------|--------------|
| 1 | Новичок | 0 |
| 2 | Стажер | 100 |
| 3 | Продвинутый | 250 |
| 4 | Специалист | 500 |
| 5 | Старший | 1000 |
| 6 | Эксперт | 2000 |
| 7 | Про | 3500 |
| 8 | Мастер | 5500 |
| 9 | Легенда | 8000 |
| 10 | Гуру | 12000 |

**Начисление опыта:**
- 📖 Урок завершен: **+10 XP**
- 📝 Тест пройден: **+30 XP**
- 💯 Тест на 100%: **+60 XP**
- 📅 Ежедневная активность: **+5 XP**
- 🎯 Квест выполнен: **+10-50 XP**

**API Endpoints:**
```
GET /academy/v1/user/{user_id}/level
```
Возвращает текущий уровень, опыт, ранг и прогресс пользователя.

**Telegram команда:**
```
/level
```
Показывает текущий уровень, ранг, XP и информацию о том, как получить опыт.

**Пример ответа API:**
```json
{
  "user_id": "12345",
  "level": 3,
  "xp": 320,
  "xp_to_next": 180,
  "rank_name": "Продвинутый",
  "updated_at": "2025-11-24T12:00:00"
}
```

**Автоматическая интеграция:**
- Опыт начисляется автоматически при завершении уроков
- Опыт начисляется при прохождении тестов
- Бонусный опыт за тест на 100%
- Уровень повышается автоматически при достижении требуемого XP

### 2️⃣ Персональный план обучения (Learning Plan)

**База данных:** Таблица `academy_learning_plan`

**Поля:**
- `user_id` - ID пользователя
- `module_id` - ID модуля
- `lesson_id` - ID урока
- `status` - Статус (pending, active, done)
- `priority` - Приоритет (1-10)
- `generated_at` - Время создания

**Алгоритм генерации:**
План создается на основе:
1. **Роли пользователя** - модули, доступные для роли
2. **Текущего прогресса** - незавершенные уроки
3. **Результатов тестов** - слабые зоны (средний балл < 70%)
4. **Незавершенных модулей** - модули в процессе изучения

**Особенности:**
- План формируется на **7 дней**
- Содержит до **20 рекомендуемых уроков**
- Высокий приоритет (10) для слабых модулей
- Средний приоритет (5) для остальных

**API Endpoints:**
```
GET /academy/v1/plan/{user_id}
POST /academy/v1/plan/{user_id}/generate
```

**Telegram команды:**
```
/plan           - Показать текущий план
/plan_refresh   - Пересоздать план
```

**Пример ответа API:**
```json
{
  "user_id": "12345",
  "items": [
    {
      "module_id": "module3_sales_f1",
      "lesson_id": "m3_l2",
      "status": "pending",
      "priority": 10,
      "generated_at": "2025-11-24T12:00:00"
    }
  ],
  "generated_at": "2025-11-24T12:00:00",
  "valid_until": "2025-12-01T12:00:00"
}
```

**Автоматическое обновление:**
- Статус урока обновляется на "done" при завершении урока
- План можно пересоздать вручную командой `/plan_refresh`

### 3️⃣ Ежедневные задания (Daily Quests)

**База данных:** Таблица `academy_daily_quests`

**Поля:**
- `quest_id` - Уникальный ID квеста
- `user_id` - ID пользователя
- `type` - Тип квеста (lesson, test, streak, tts, module)
- `description` - Описание задания
- `reward_xp` - Награда в XP
- `status` - Статус (active, completed, expired)
- `date` - Дата (YYYY-MM-DD)
- `created_at` - Время создания
- `completed_at` - Время завершения

**Типы квестов:**
| Тип | Описание | Награда XP |
|-----|----------|------------|
| lesson | Пройти 1 урок | +15 |
| test | Пройти тест | +40 |
| streak | Учиться 20 минут | +25 |
| tts | Получить аудиоверсию урока | +10 |
| module | Завершить модуль | +50 |

**Генерация квестов:**
- Автоматически при первом запросе дня
- Каждый день генерируется **3 случайных квеста**
- Старые квесты автоматически помечаются как "expired"

**API Endpoints:**
```
GET /academy/v1/quests/{user_id}
POST /academy/v1/quests/{user_id}/complete/{quest_id}
```

**Telegram команда:**
```
/quests
```
Показывает активные и выполненные квесты на сегодня.

**Автоматическое завершение:**
Квесты завершаются автоматически при выполнении действий:
- Завершение урока → проверка квеста "lesson"
- Прохождение теста → проверка квеста "test"
- Генерация TTS → проверка квеста "tts"

**Пример ответа API:**
```json
[
  {
    "quest_id": "abc-123",
    "user_id": "12345",
    "type": "lesson",
    "description": "Пройти 1 урок",
    "reward_xp": 15,
    "status": "completed",
    "date": "2025-11-24",
    "created_at": "2025-11-24T00:00:00"
  }
]
```

### 4️⃣ Мегастатистика для администраторов (Mega Stats)

**API Endpoint:**
```
GET /academy/v1/admin/mega_stats
```
Требуется заголовок `X-Admin-Token` с правильным ключом.

**Возвращает:**

**1. Общие данные:**
- Количество пользователей
- Активных за сегодня
- Активных за неделю
- Активных за месяц

**2. По ролям:**
- Распределение пользователей по ролям
- Менеджеры, генераторы, админы

**3. По модулям:**
- **Топ-5 самых изучаемых модулей**
  - ID модуля, название, количество пользователей
- **Топ-5 самых сложных модулей**
  - ID модуля, название, средний балл тестов
- **Модули, которые никто не изучает**
  - ID модуля, название, описание

**4. По тестам:**
- **Средний балл по системе**
- **Самые провальные вопросы**
  - ID теста, количество попыток, процент успеха
- **Модули с низкой успеваемостью**

### 5️⃣ Улучшенный TTS (Enhanced TTS Settings)

**База данных:** Таблица `academy_tts_settings`

**Поля:**
- `user_id` - ID пользователя
- `voice` - Голос (female, male, neutral)
- `speed` - Скорость (1.0, 1.25, 1.5)
- `format` - Формат (ogg, mp3)
- `updated_at` - Время последнего обновления

**Поддерживаемые параметры:**

**Голоса:**
- `female` - Женский голос (по умолчанию)
- `male` - Мужской голос
- `neutral` - Нейтральный голос

**Скорость:**
- `1.0` - Нормальная скорость (по умолчанию)
- `1.25` - Ускоренная на 25%
- `1.5` - Ускоренная на 50%

**Форматы:**
- `mp3` - MP3 формат (по умолчанию)
- `ogg` - OGG формат

**API Endpoints:**
```
GET /academy/v1/tts/settings/{user_id}
POST /academy/v1/tts/settings/{user_id}
```

**Telegram команда:**
```
/tts_settings
```
Показывает текущие настройки TTS пользователя.

**Пример запроса обновления:**
```json
{
  "voice": "male",
  "speed": "1.25",
  "format": "mp3"
}
```

**Примечание:** 
В текущей версии настройки сохраняются в базе данных. Применение скорости и формата будет реализовано в будущих версиях с использованием библиотек обработки аудио (например, pydub).

## 🔧 Технические детали

### Автоматическая инициализация

Все V3 таблицы создаются автоматически при первом запуске:
- `academy_levels`
- `academy_xp_history`
- `academy_learning_plan`
- `academy_daily_quests`
- `academy_tts_settings`

### Интеграция с существующей системой

V3 функции интегрированы в существующие endpoints:

**Завершение урока:**
```python
POST /academy/v1/progress/{user_id}/lessons/{module_id}/{lesson_id}/complete
```
- Начисляет +10 XP
- Проверяет и завершает квест "lesson"
- Обновляет статус в плане обучения

**Прохождение теста:**
```python
POST /academy/v1/modules/{module_id}/tests/{test_id}/submit
```
- Начисляет +30 XP (или +60 XP за 100%)
- Проверяет и завершает квест "test"

**Генерация TTS:**
```python
POST /academy/v1/lessons/{module_id}/{lesson_id}/tts?user_id={user_id}
```
- Проверяет и завершает квест "tts"
